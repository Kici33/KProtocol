Using Docker to build and test kprotocol

This repository includes a Dockerfile that sets up a reproducible environment for generating packets, building the C++ library, and running tests.

Build and start a container (recommended for environments without CMake or a C++ toolchain):

```bash
# build image (from repo root)
docker build -t kprotocol-build .

# start an interactive shell inside container
docker run --rm -it -v ${PWD}:/workspace kprotocol-build
```

The Docker image will attempt to run the generator (generate_packets_v3.js) and build the project with CMake. Generated headers will be placed under generated/ and copied into include/kprotocol/generated by the repository scripts.

Notes
- The Docker build is best-effort and does not fail the image build if generation or tests fail. Inspect the build logs inside the container for details.
- For CI a GitHub Actions workflow is included at .github/workflows/ci.yml to run the same steps on push/pull_request.
